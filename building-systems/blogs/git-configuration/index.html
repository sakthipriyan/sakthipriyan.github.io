Git Configuration

Alias for generally used Git commands

📅 Apr 1, 2015 🔄 Aug 23, 2026 💻 Source 📖 1 min read

Following configuration can be used to speed up git usage.

Edit Content

nano ~/.gitconfig

Config Content

[user]
name = Sakthi Priyan H
email = **************

[alias]
br = branch
cm = commit -m
ca = commit -a -m
co = checkout
pr = pull --rebase
pu = push
re = rebase
st = status
tp = push --tags
